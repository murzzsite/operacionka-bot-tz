# operacionka-bot-tz

Технические задания для бота Операционки (клиенты пишут в тему форума, ответы менеджера уходят клиенту в бота).

## Сейчас в работе

- [TZ_autoreply.md](TZ_autoreply.md): автоответ клиентам в нерабочее время (будни 10:00-17:00 МСК, выходные, праздники).
- [ACCEPTANCE.md](ACCEPTANCE.md): чек-лист приёмки, 50 кейсов с временами.
- Issue «Автоответ про нерабочее время»: то же самое одним текстом для обсуждения и вопросов.

## Суть

Клиент, написавший вечером, ночью, в выходной или праздник, получает короткий автоответ с графиком работы. Не чаще одного раза за окно нерабочего времени, не на команды, кнопки и «Старт», не при живом диалоге с менеджером. Автоответ не считается ответом менеджера, в теме остаётся пометка «🤖 автоответ отправлен». Включение и выключение командами /автоответ_вкл, /автоответ_выкл, текст через /автоответ_текст.

## Вопросы

Раздел 13 в TZ_autoreply.md: вопросы к программисту по устройству бота. Пишите ответы в комментариях к Issue.

Секреты и токены в репозиторий не кладём.
